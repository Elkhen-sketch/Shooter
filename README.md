# 🌸 Spreading Love: A Non-Violent Shooter Game

**Author:** Enkhtushig Legdenbold  
**Student ID:** D24125405

## 🎮 Project Overview

“**Spreading Love**” is a creatively reimagined non-violent shooter game, designed as part of an academic assignment. Unlike traditional shooters, this game features a peaceful alien protagonist whose goal is to spread love and happiness by shooting flowers. When other characters receive a flower, they are transformed by love—symbolized by joyful, romantic expressions and behavior.

## 🏞️ Game Environment

The game takes place in a **Love Garden**, a whimsical and serene space filled with charming details such as:

- Flowering trees and romantic benches  
- Warm, colorful visuals  
- A calm, magical atmosphere  

The environment and characters are carefully designed to complement each other and reinforce the non-violent theme.

## 🕹️ Game Controls

| Key     | Action         |
|---------|----------------|
| `S`     | Shoot Flower   |
| `Space` | Jump           |
| `A`     | Move Left      |
| `D`     | Move Right     |

🗺️ *Note: The game map scrolls upward as you progress.*

## ⚙️ How It Works

- The initial levels allow players to experiment with basic mechanics like jumping, moving, and shooting.  
- As the game progresses, level design becomes more complex and introduces puzzle-like challenges.  
- Some areas are hidden or hard to access, encouraging creative problem-solving and exploration.

## 🧠 Game Mechanics

- Run, Jump, Shoot (flower projectiles)  
- **Enemy Behavior**: Enemies are sad, emotional beings. When hit by a flower, they become happy and filled with love—reinforcing the peaceful theme.  
- **Hidden Corners**: Secret zones reward players who explore thoroughly.
